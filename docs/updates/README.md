# docs/updates/

更新日志、变更记录、版本说明、会议纪要。

## 用途

存放项目的版本更新记录，包括：
- Changelog
- Breaking changes 记录
- 版本升级指南
- 功能更新说明
- 同步会 / 决策会记录（保留转写原文，不做纪要式改写）

## 现有文档

- [meeting-2026-08-15-first-sync.md](./meeting-2026-08-15-first-sync.md) — 第一次同步会：转写原文（一字未改）+ Step 1–6 全景路线图

## 文件命名

- `changelog.md` — 累积变更日志
- `update-<version>.md` — 单个版本的更新说明
- `breaking-<version>.md` — 破坏性变更说明
- `meeting-YYYY-MM-DD-<brief>.md` — 会议纪要
