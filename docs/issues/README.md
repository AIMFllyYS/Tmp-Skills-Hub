# docs/issues/

问题追踪与记录。

## 用途

存放项目中的已知问题、bug 记录和技术债务，包括：
- 已知问题列表
- Bug 记录与修复追踪
- 技术债务登记
- 临时绕过方案的记录与待修复标记
- 会上明确后置、但第一天就要登记的需求

## 现有文档

- [backlog-from-first-sync.md](./backlog-from-first-sync.md) — 第一次同步会后置项
- [skill-creation-path/](./skill-creation-path/) — 用户在客户端里**新建** skill 这条路径的分析与追踪（对应 [#169](https://github.com/AIMFllyYS/Tmp-Skills-Hub/issues/169)）

## 与 GitHub Issues 的关系

GitHub Issues 用于外部协作和任务追踪，本目录用于项目内部的问题归档和技术债务管理。远程仓库仍是空仓且当前无写权限时，先写在这里。

## 文件命名

- `known-issues.md` — 当前已知问题汇总
- `issue-<number>-<brief>.md` — 单个问题详情
- `tech-debt.md` — 技术债务登记簿
- `backlog-from-<source>.md` — 从会议/调研转入的后置清单
