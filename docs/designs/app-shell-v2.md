# 人用壳信息架构 v2

> 状态:生效 | 对应 issue:#160
> 人打开的是这个壳。数据层约束(链接按行暴露、批量一次原子提交)仍见 [panel-ia-v1.md](panel-ia-v1.md)。
> 视觉服从 [ui-design-v0.md](../conventions/ui-design-v0.md)。

## 受众

人只通过 `bootstrap` / `ui` 进 WebUI。CLI 给 Agent 与脚本。

## 骨架

左侧固定三个板块:**总览** / **统计** / **Skills 管理**。左下角:**设置**。主区吃满剩余宽度。没有常驻检查器,没有把过滤器当一级导航。

```
+------------+-----------------------------+
| 总览       |                             |
| 统计       |            主区             |
| Skills 管理|                             |
|            |                             |
| 设置       |                             |
+------------+-----------------------------+
```

## 页面

1. **总览** — 一眼健康:库存数、覆盖、应用数、需要处理的事、近期活动。能点进另外两页。
2. **统计** — 页内 tab:用量、应用分布(IDE/CLI)、来源(有数据再亮)。
3. **Skills 管理** — 两个全幅 tab:
   - **应用**:选一个应用,开/关它看见的 skill。
   - **内容**:左树右文,读/编/存。
4. **设置** — 库存路径只读、已发现应用、重置按钮 + 确认弹窗。确认后打现有 `POST /api/reset`。不在本壳修重置内核。

主路径不放哈希、命令面板、verify/doctor 原文。滚动条隐藏、滚动保留。
