# 人用壳信息架构 v2

> 状态:生效 | 对应 issue:#160
> 人打开的是这个壳。数据层约束(链接按行暴露、批量一次原子提交)仍见 [panel-ia-v1.md](panel-ia-v1.md)。
> 视觉与旅程服从 [ui-design-v1.md](../conventions/ui-design-v1.md)（v0 已并入）。

## 受众

人只通过 `bootstrap` / `ui` 进 WebUI。CLI 给 Agent 与脚本。

## 骨架

左侧固定三个板块:**总览** / **统计** / **Skills 管理**。左下角:**设置**。主区吃满剩余宽度。没有常驻检查器,没有把过滤器当一级导航。

```
+------------+-----------------------------+
| 总览       |                             |
| 统计       |            主区             |
| Skills 管理|                             |
|            |                             |
| 设置       |                             |
+------------+-----------------------------+
```

## 页面

1. **总览** — 一眼健康:库存数、覆盖、应用数、需要处理的事、近期活动。能点进另外两页。
2. **统计** — 页内 tab:用量、应用分布(IDE/CLI)、来源(有数据再亮)。
3. **Skills 管理** — 两个全幅 tab:
   - **应用**:选一个应用,开/关它看见的 skill。库存默认属于全部已发现应用;未启用 = 尚未挂链接,不是未授权。空覆盖时主动作是「全部启用」。提供「全部启用 / 全部停用」(当前应用)与「启用到全部应用」。落点已被本地目录占用的条目跳过、不覆盖。系统目录(如 `.codex/skills/.system`)不在此列。成功后磁盘立刻改掉;正在运行的 IDE 可能仍要新开对话。应用列按已启用数、其次常用 id 排序,不改发现规则。禁止打开面板就静默全开。
   - **内容**:左树右文,读/编/存。收录 / 创建走对话框,默认勾选「同时启用到全部已发现应用」。应用页与内容页都可搜索名称/描述。分组过滤与「分析 / 分享 / 归档」是选中 skill 后的次级动作,不是左侧导航。
4. **设置** — 库存路径只读、已发现应用、重置按钮 + 确认弹窗。确认后打现有 `POST /api/reset`。不在本壳修重置内核。

主路径不放哈希、命令面板、verify/doctor 原文。滚动条隐藏、滚动保留。控件来源与空状态 / Toast / 对话框规则见 [ui-design-v1.md](../conventions/ui-design-v1.md) §8–§9。
